# Estudos JavaScript

Este projeto foi desenvolvido como parte dos meus estudos de **JavaScript**(sem frameworks). O objetivo foi praticar a manipulação do DOM, persistência de dados no navegador e lógica de programação.

## Conteúdo:
- **Lista de Tarefas:** Um gerenciador de tarefas onde é possível adicionar, marcar como concluído e remover itens.  
- **Calculadora:** Uma calculadora criada para praticar operações matemáticas e manipulação de eventos de clique.
- **Manipulação do DOM:** Criar, remover e atualizar elementos HTML dinamicamente.  
- **Armazenamento Local:** Uso do `localStorage` para manter os dados mesmo após recarregar ou trocar a página.  

## Tecnologias utilizadas:
- HTML5  
- CSS3  
- JavaScript
